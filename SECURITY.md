# Security

Do not post secrets, credentials or exploitable production details in public issues. Use the repository owner's GitHub profile to arrange a private report before sharing sensitive details. There is no staffed incident-response service or response-time guarantee.

Supported version: the latest 0.1.x source release. Reports are untrusted input: XML declarations for DTD/entities are rejected and byte/observation limits apply. HTML uses text nodes and escaped JSON. These defenses do not replace operating-system resource limits when processing hostile bulk data.

The database and output files can retain failure text and names. Redact at the source, restrict access and review before publishing. No telemetry or outbound runtime integrations are implemented.
